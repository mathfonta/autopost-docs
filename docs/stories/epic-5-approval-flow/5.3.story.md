# Story 5.3 — Menu de Intenção antes do Upload

**Status:** Done  
**Epic:** 5 — Fluxo de Aprovação Avançado  
**Story:** 5.3  
**Estimativa:** 3 pontos  
**Depende de:** Story 4.2 (PhotoUploadFAB existente)

---

## Descrição

Como cliente AutoPost, quero escolher o tipo de conteúdo que quero criar antes de enviar a foto — para que o agente gere uma legenda adequada ao formato escolhido, sem eu precisar editar depois.

---

## Critérios de Aceitação

- [ ] AC1: Ao clicar no FAB "Nova Foto", antes de abrir o file picker, exibe um bottom sheet / modal com as opções de intenção
- [ ] AC2: Opções disponíveis no MVP (ícone + rótulo):
  - 📸 Post Simples — publicação de obra ou produto
  - 🔨 Obra em Andamento — progresso de projeto
  - ✅ Obra Concluída — resultado final
  - 💬 Engajamento — pergunta ou enquete para a audiência
  - 🎉 Bastidores — momento da equipe ou processo
- [ ] AC3: Usuário seleciona uma opção → file picker abre normalmente
- [ ] AC4: Opção selecionada é enviada no campo `content_type` do `POST /content-requests`
- [ ] AC5: O Agente Copywriter recebe `content_type` no contexto e adapta o tom e estrutura da legenda
- [ ] AC6: Na prévia, o tipo de conteúdo selecionado é exibido como badge discreto ("Obra Concluída")
- [ ] AC7: Se usuário fechar o bottom sheet sem selecionar, nada acontece (fluxo cancelado)

---

## Escopo

**IN:**
- Bottom sheet de seleção de intenção no mobile, modal no desktop
- 5 tipos de conteúdo para o MVP
- `content_type` passado ao backend e usado pelo Copywriter
- Badge do tipo na tela de aprovação

**OUT:**
- Carrossel e Antes/Depois (requer múltiplas fotos — Story futura)
- Reels/Roteiro (v2.0)
- Criação de tipos customizados pelo usuário
- Seleção de intenção na tela de Histórico
